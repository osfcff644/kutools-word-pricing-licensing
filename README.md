## 哪些人该买，哪些人其实不用

先说该买的。每天要在 Word 里处理长文档的人，收益最直接。这插件的功能是按场景分组的，装上后 Word 顶部会多出一个 Kutools 选项卡，批量转图片、批量删空行、题注自动编号、跨文档查找替换这些重复动作，都能从几步操作压成一键。写论文、做标书、整理合同、排版手册，这些活儿里它省下来的时间是以小时计的。

再说不用买的，这部分更重要。

只用 WPS 的人不用买。这插件只挂载在 Microsoft Word 上，WPS 打不开它。

用 Mac 的人不用买。官方写得很明确，不支持 macOS，Windows 11 到 Windows 7 都行，甚至支持 Server 系列和 Citrix 环境，就是没有 Mac 版本。

偶尔改改文档格式的人也不用买。一个月打开 Word 不到十次，需要的只是调个字号、改个行距，Word 自带的功能够了，装插件反而多一个启动项。

还有一种情况：你只是想用 AI 写东西。KuTools 里确实带了 AI 辅助，但需要你自己去申请并配置 API Key，比如 DeepSeek、通义千问这类，调用产生的费用另算。冲着"自带 AI"来的话，它不算开箱即用。

## 真实评价和几个必须知道的限制

公开的独立评测不算多。Trustpilot 上有用户评价 Kutools 系列"帮助更高效地管理文档和邮件"，整体偏正面但样本量不大。ColorMango 给 Kutools for Word 的用户评分是 4.5 分（满分 5 分），83% 的评分是五星。ExtendOffice 官方披露的数据是全球 50 万以上用户、8 万多家企业，这是厂商口径，当作规模参考可以，别当独立背书。

比评价更值得看的是条款，这里有几个坑，买之前必须知道。

第一，数字商品发货后不退。荔枝商店的购买须知写得很直白，数字商品一经交付不予退款，除非当地法律另有要求。这意味着买错版本没法退，所以务必先用 30 天全功能试用版试一遍，确认能在你的 Word 版本上正常跑起来再付钱。

第二，2 年免费升级不等于永久升级。买断的是使用权限，2 年内的大版本更新免费，之后开发商如果推出新版本并单独收费，那是开发商的策略，销售渠道不承担补偿或退款责任。购买须知里对"终身""永久更新"这类措辞有明确免责说明，这些承诺的解释权在开发商手里。

第三，2 台设备的限制是硬的。一个授权码最多激活 2 台机器，公司里三个人用就得买 3 个授权。共享、转售、出租都在禁止范围内，违反的后果由使用者承担。

第四，只支持 Windows。这条前面说过，但它是最容易买错的一点。Office 2013 到 2024 以及 Microsoft 365 都支持，32 位和 64 位都行，就是不支持 Mac。
